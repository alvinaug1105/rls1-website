# RLS1 Media Centre and session countdown

1. **Media Centre:** Added protected `/admin/media`, navigation and dashboard quick access. It defaults through the existing current-round helper. Round-specific official qualifying, Duel and race graphics plus WDC/WCC through the selected round use shared result/standings functions. Missing results disable generation. Preview All renders available images with individual download links. Existing fixed-resolution renderers and long-name handling are retained.
2. **Public controls:** Removed PNG controls from qualifying, Duel, race and championship views. Removed race CSV export as part of spectator-focused cleanup. Results, standings and brackets remain visible.
3. **Discord recap:** Removed buttons, fallback dialog, imports and recap-only functions. Other Discord functionality is untouched.
4. **Countdown:** Shared pure `sessionState` and `SessionCountdown` power home, the selected current-round page and admin dashboard. The timer updates each second and cleans up its interval. It never displays negative time. Completed historical pages keep their completed badge.
5. **Notices:** More than 24 hours shows the schedule; within 24 hours shows the clock; one-hour and fifteen-minute windows receive stronger wording. The first minute shows Starting now, followed by the current stage. Notices are derived in memory, without database writes or browser notification permissions.
6. **Schedule:** `SESSION_SCHEDULE` in `app/racing.ts` centralises fixed qualifying at 21:00 with `Asia/Hong_Kong`. Duel and Race fixed times remain null because no fixed times are defined. The existing optional event startAt remains stored; it is not treated as a fixed Duel/Race schedule.
7. **Race week:** Existing Wednesday–Sunday selection, Monday/Tuesday transition and official-state priority are preserved. No archive or standings edits, schema migration or production deployment.
8. **Admin dashboard:** Includes the same session component and Media Centre shortcut. Media Centre uses the existing server authentication gate.
9. **Files:** New app/session.ts, app/session-countdown.tsx, app/media.ts, app/admin/media-centre.tsx and app/admin/media/page.tsx. Updated racing.ts, race-ui.tsx, dashboard.tsx, season-views.tsx, qualifying-card.tsx, championship.tsx, duel-ui.tsx, admin/portal.tsx, polish.css, tests/racing.mjs and tests/admin-http.py.
10. **Tests:** TypeScript, lint, racing/archive/race-week tests, admin-session tests, PNG tests and production build passed. Added countdown boundaries (one hour, fifteen minutes, one second, exact start, after start), completion, media availability and public-control absence checks. Admin HTTP tests include the new protected route and passed; Duel integration passed. Browser confirmed Spain default, disabled missing results and four generated Preview All images for Australia. Home session and Media Centre layout checked at 375/430/768/1024/1440 without page-wide overflow.
11. **Limitations:** Optional Download All archive is not implemented; Preview All provides individual PNG download links. No invented Duel/Race times. Browser checks used Chrome; not a full Safari/screen-reader audit. Countdown uses the device clock interpreted in HKT, so an incorrectly configured device clock can affect its accuracy. No production changes.
